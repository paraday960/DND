# 🐉 D&D Bot — دانجن‌مستر هوشمند تلگرام

ربات تلگرامی بازی **Dungeons & Dragons** با دانجن‌مستر **هوش مصنوعی** — تا **۸ بازیکن**،
طراحی سناریو و روایت داستان با AI، **کاملاً رایگان**، و قابلیت اجرا روی **گوشی اندروید** به‌عنوان سرور!

---

## 🤖 قوانین الزامی برای ایجنت‌های هوش مصنوعی

> ⚠️ **این قوانین برای هر ایجنت / دستیار هوش مصنوعی که به این ریپو وصل می‌شود الزامی است.**
> با اتصال به این ریپو و خواندن این بخش، ایجنت خود را موظف به رعایت کامل و بی‌قید‌وشرط آن‌ها می‌داند.
> نقض هر یک از این قوانین = خروجی نامعتبر.

### 🔴 قانون اصلی — کار ریموت‌-اول (Remote-First)
- **گیت‌هاب تنها منبع حقیقت** (single source of truth) است و **همیشه باید به‌روز باشد**.
- **همهٔ کارها باید به‌صورت ریموت روی گیت‌هاب انجام شود**: هر تغییر (کد، فایل، مستندات، تنظیمات)
  باید بلافاصله پس از اتمام، `commit` شده و به `origin` روی گیت‌هاب `push` گردد.
- رها کردن کاری به‌صورت محلی (روی سندباکس) بدون push **مطلقاً ممنوع** است.
- قبل از پایان هر نشست کاری، ایجنت موظف است با `git status` بررسی کند که چیزی unpush باقی نمانده باشد
  و ریپوی ریموت دقیقاً آخرین وضعیت را داشته باشد.
- ایجنت هرگز نباید فرض کند که سندباکس بین نشست‌ها پایدار می‌ماند — تنها گیت‌هاب قابل اعتماد است.

### 🟡 قانون ۲ — ایمنی سندباکس (Sandbox-Safe Execution)
- قبل از شروع کار، ایجنت **باید** محیط سندباکس/ورک‌اسپیس را بررسی کند:
  منابع موجود (دیسک، رم، CPU)، ابزارهای نصب‌شده، و ساختار فایل‌ها.
- کارها باید طوری طراحی و اجرا شوند که سندباکس **هنگ نکند**:
  - از پروسه‌های سنگین بی‌پایان، حلقه‌های بی‌نهایت، و بیلدهای موازی سنگین پرهیز شود.
  - از دانلودها و نصب‌های غیرضروری اجتناب شود.
  - سرورهای بلندمدت (dev server, watcher) فقط درصورت نیاز واقعی و با ابزار `start_process` اجرا شوند
    (نه با `bash` معمولی) و در پایان کار با `stop_process` متوقف گردند.

### 🟠 قانون ۳ — تایم‌اوت منطقی برای همهٔ کارها (Always-Set Timeouts)
- **هر دستور، هر فراخوانی ابزار، و هر عملیات باید تایم‌اوت منطقی و مشخصی داشته باشد** تا هیچ‌گاه در جایی گیر نکند.
- برای دستورات bash: پارامتر `timeout` همیشه تنظیم شود (پیش‌فرض ۳۰ ثانیه؛ برای کارهای سنگین‌تر حداکثر
  مقدار معقول و متناسب با کار؛ هرگز بی‌نهایت رها نشود).
- برای انتظار روی پروسه‌ها: از `wait_for` با `wait_timeout` معقول استفاده شود، نه polling دستی یا `sleep` در حلقه.
- در صورت timeout: ایجنت باید مشکل را تشخیص دهد، راه حل جایگزین امتحان کند، یا صریحاً به کاربر گزارش دهد —
  هرگز نباید بی‌پاسخ منتظر بماند.

### 🟢 قانون ۴ — پاک‌سازی سندباکس (Clean Sandbox)
- سندباکس/ورک‌اسپیس فقط **ابزار کار موقت** است، نه محل نگهداری دائمی فایل‌ها.
- حافظهٔ سندباکس باید **همیشه خالی بماند**:
  - اگر در طول کاری فایل موقتی در سندباکس ساخته شد (لاگ، خروجی، کش، فایل تستی و...)،
    **بلافاصله بعد از اتمام کار و بعد از push شدن نتیجه روی گیت‌هاب، باید آن فایل‌ها پاک شوند**.
  - کش‌ها و دایرکتوری‌های build (مانند `node_modules/`, `__pycache__/`, `.venv/` و...)
    هرگز commit نشوند و در صورت ایجاد موقت، پاک شوند.
  - قبل از پایان نشست: `git status` بررسی شود که فقط فایل‌های tracked و متعهد‌شده باقی مانده باشند.
  - فایل‌های حساس (توکن، `.env`) هرگز commit نشوند.

### ✅ چک‌لیست پایان هر نشست برای ایجنت
1. `git status` — آیا همه چیز commit شده؟
2. `git log -1` با `origin/main` مقایسه شود — آیا همه چیز push شده؟
3. آیا تمام پروسه‌های پس‌زمینه متوقف شده‌اند؟
4. آیا فایل‌های موقت/لاگ/کش پاک شده‌اند؟
5. آیا همه دستورات با تایم‌اوت اجرا شده‌اند و هیچ‌چیز معلق/گیر نیفتاده است؟
6. در صورت منفی بودن پاسخ هر مورد، ایجنت **موظف** است قبل از خداحافظی آن را اصلاح کند.

## ⚡ سریع‌ترین راه: نصب اپ اندروید (APK)

**📥 لینک دانلود مستقیم آخرین نسخه:**
[👉 **DnD-Bot.apk** — دانلود از ریلیز `latest`](https://github.com/paraday960/DND/releases/latest/download/DnD-Bot.apk)

(هر بار که کد آپدیت می‌شود، این لینک همیشه آخرین نسخه را می‌دهد.)

**۱.** فایل `DnD-Bot.apk` را از لینک بالا دانلود کن
(در تنظیمات، «نصب از منابع ناشناس» را اجازه بده).

**۲.** اپ را باز کن — توکن ربات و کلید هوش مصنوعی را از صفحه تنظیمات وارد کن
(می‌توانی از کلید رایگان Mistral استفاده کنی).

**۳.** دکمه **«▶️ شروع سرور»** را بزن — همین! 🎉

اپ خودش این کارها را انجام می‌دهد:
- ربات تلگرام را روشن می‌کند (polling — بدون نیاز به IP عمومی)
- وب‌سرور مینی‌گیم را بالا می‌آورد
- تونل امن رایگان Cloudflare را می‌سازد (برای دکمه بازی داخل ربات)
- گوشی را بیدار نگه می‌دارد (Wake Lock) و در پس‌زمینه کار می‌کند

بعدش در تلگرام به رباتت `/start` بزن و دکمه **«🎮 ورود به مینی‌گیم»** را لمس کن!

> 📦 برای ساخت دوباره APK: کد در پوشه `android/` است؛ یا از تب **Actions** گیت‌هاب
> (workflow خودکار) استفاده کن — APK آماده دانلود می‌شود.

## ⚡ راه‌اندازی سریع روی گوشی (Termux — ۵ دقیقه)

> 💡 گوشی اندرویدت را سرور کن! ربات روی گوشی با شبکه خودت ۲۴/۷ کار می‌کند — بدون نیاز به هاست خارجی.

**۱. نصب Termux** از F-Droid: https://f-droid.org/packages/com.termux/

**۲. کپی پروژه (کدها از قبل روی گیت‌هاب است):**
```bash
pkg install -y git
git clone https://github.com/paraday960/DND.git
cd DND
```

**۳. نصب خودکار همه‌چیز (یک دستور):**
```bash
bash termux/setup.sh
```

**۴. تنظیمات (توکن ربات و کلید AI):**
```bash
cp .env.example .env
nano .env
```
> توکن ربات را از @BotFather بگیر؛ کلید AI رایگان را از https://console.mistral.ai (یا Gemini/Groq — راهنما داخل .env.example)

**۵. اجرا:**
```bash
bash termux/run.sh
```
ربات + تونل امن مینی‌گیم خودکار بالا می‌آیند. همین! 🎉

**۶. (اختیاری) راه‌اندازی خودکار با روشن شدن گوشی:**
```bash
pkg install -y termux-boot
mkdir -p ~/.termux/boot
cp termux/boot.sh ~/.termux/boot/
```

> ⚙️ در تنظیمات باتری اندروید، Termux را از «بهینه‌سازی باتری» مستثنی کن.

## 🎮 مینی‌گیم داخل تلگرام (Telegram Mini App)

ربات یک **مینی‌گیم گرافیکی** دارد: با دکمه «🎮 ورود به مینی‌گیم» (داخل ربات بعد از `/start`)
بازی باز می‌شود — ساخت اتاق، کاراکتر، سناریو، روایت و نبرد همه داخل بازی با دکمه انجام می‌شود.

مینی‌گیم به یک **آدرس HTTPS** نیاز دارد. ساده‌ترین راه (رایگان):

```bash
# روی گوشی (Termux) — تونل رایگان Cloudflare
bash termux/tunnel.sh
```

یا در `.env` مقدار `WEBAPP_URL=https://your-domain.com` را بگذار.
> نکته: در حالت عادی امنیت با امضای initData تلگرام بررسی می‌شود؛
> `WEBAPP_DEV=0` باشد (پیش‌فرض). برای تست محلی می‌توانی `WEBAPP_DEV=1` کنی.

### گرفتن توکن ربات (۳۰ ثانیه)
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. `/newbot` → اسم ربات → یوزرنیم (مثلاً `MyDnD_Bot`)
3. توکنی که می‌ده (مثل `123456:ABC...`) را در `.env` بگذار

## 📱 راه‌اندازی روی گوشی اندروید (گوشی = سرور)

ربات از **long-polling** استفاده می‌کند؛ یعنی گوشی فقط باید اینترنت داشته باشد —
نیازی به IP عمومی، پورت‌فوروارد یا هاست خارجی نیست. گوشی خودت، سرور خودته! 🎉

### قدم ۱ — نصب Termux
- از **F-Droid** (نسخه به‌روز): https://f-droid.org/packages/com.termux/
  (نسخه گوگل‌پلی قدیمی است؛ F-Droid را پیشنهاد می‌کنیم)

### قدم ۲ — نصب پروژه
```bash
pkg install -y git
git clone https://github.com/paraday960/DND.git
cd DND
```

### قدم ۳ — نصب خودکار (یک‌دستوری)
```bash
bash termux/setup.sh
```

### قدم ۴ — تنظیمات
```bash
cp .env.example .env
nano .env     # توکن ربات و کلید AI
```

### قدم ۵ — اجرا
```bash
bash termux/run.sh
```
ربات با **Wake Lock** روشن می‌ماند و اگر خطایی پیش بیاید خودکار دوباره شروع می‌شود.

### 🚀 راه‌اندازی خودکار با روشن شدن گوشی
```bash
pkg install -y termux-boot   # از F-Droid: اپ Termux:Boot را نصب کن
mkdir -p ~/.termux/boot
cp termux/boot.sh ~/.termux/boot/
```
از این به بعد، هر بار گوشی روشن شود، ربات خودکار بالا می‌آید! 🔄

> 💡 نکته: در تنظیمات باتری اندروید، Termux را از «بهینه‌سازی باتری» مستثنی کن
> تا سیستم عامل آن را نکشد.

## 🎮 چطور بازی کنیم؟

1. **گروه بساز** — یک گروه تلگرامی بساز و ربات را به آن اضافه کن
2. **میزبان** → `/newgame` — کد اتاق ساخته می‌شود (مثل `K7Q2A`)
3. **بازیکن‌ها** → `/join K7Q2A` — ملحق می‌شوند (تا ۸ نفر)
4. **همه** → `/newchar` — نام، نژاد، کلاس و سلاح خود را انتخاب می‌کنند
5. **میزبان** → `/scenario` — هوش مصنوعی یک سناریوی کامل با دشمن‌ها و NPC می‌سازد
6. **شروع ماجرا** → `/story درِ کهنه را باز می‌کنم` — AI روایت می‌کند!
7. **نبرد** → `/combat` — نوبت‌ها خودکار می‌چرخد، دشمن‌ها خودشان حمله می‌کنند
