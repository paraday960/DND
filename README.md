# 🐉 D&D Bot — دانجن‌مستر هوشمند تلگرام

ربات تلگرامی بازی **Dungeons & Dragons** با دانجن‌مستر **هوش مصنوعی** — تا **۸ بازیکن**،
طراحی سناریو و روایت داستان با AI، **کاملاً رایگان**، و قابلیت اجرا روی **گوشی اندروید** به‌عنوان سرور!

## 🚀 راه‌اندازی (کامپیوتر)

```bash
git clone https://github.com/paraday960/DND.git
cd DND
pip install -r requirements.txt

cp .env.example .env
nano .env        # توکن ربات و کلید AI را وارد کن

python main.py
```

## 🎮 مینی‌گیم داخل تلگرام (Telegram Mini App)

ربات یک **مینی‌گیم گرافیکی** دارد: با دکمه «🎮 ورود به مینی‌گیم» (داخل ربات بعد از `/start`)
بازی باز می‌شود — ساخت اتاق، کاراکتر، سناریو، روایت و نبرد همه داخل بازی با دکمه انجام می‌شود.

مینی‌گیم به یک **آدرس HTTPS** نیاز دارد. ساده‌ترین راه (رایگان):

```bash
# روی گوشی (Termux) — تونل رایگان Cloudflare
bash termux/tunnel.sh
```

یا در `.env` مقدار `WEBAPP_URL=https://your-domain.com` را بگذار.
> نکته: در حالت عادی امنیت با امضای initData تلگرام بررسی می‌شود؛
> `WEBAPP_DEV=0` باشد (پیش‌فرض). برای تست محلی می‌توانی `WEBAPP_DEV=1` کنی.

### گرفتن توکن ربات (۳۰ ثانیه)
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. `/newbot` → اسم ربات → یوزرنیم (مثلاً `MyDnD_Bot`)
3. توکنی که می‌ده (مثل `123456:ABC...`) را در `.env` بگذار

## 📱 راه‌اندازی روی گوشی اندروید (گوشی = سرور)

ربات از **long-polling** استفاده می‌کند؛ یعنی گوشی فقط باید اینترنت داشته باشد —
نیازی به IP عمومی، پورت‌فوروارد یا هاست خارجی نیست. گوشی خودت، سرور خودته! 🎉

### قدم ۱ — نصب Termux
- از **F-Droid** (نسخه به‌روز): https://f-droid.org/packages/com.termux/
  (نسخه گوگل‌پلی قدیمی است؛ F-Droid را پیشنهاد می‌کنیم)

### قدم ۲ — نصب پروژه
```bash
pkg install -y git
git clone https://github.com/paraday960/DND.git
cd DND
```

### قدم ۳ — نصب خودکار (یک‌دستوری)
```bash
bash termux/setup.sh
```

### قدم ۴ — تنظیمات
```bash
cp .env.example .env
nano .env     # توکن ربات و کلید AI
```

### قدم ۵ — اجرا
```bash
bash termux/run.sh
```
ربات با **Wake Lock** روشن می‌ماند و اگر خطایی پیش بیاید خودکار دوباره شروع می‌شود.

### 🚀 راه‌اندازی خودکار با روشن شدن گوشی
```bash
pkg install -y termux-boot   # از F-Droid: اپ Termux:Boot را نصب کن
mkdir -p ~/.termux/boot
cp termux/boot.sh ~/.termux/boot/
```
از این به بعد، هر بار گوشی روشن شود، ربات خودکار بالا می‌آید! 🔄

> 💡 نکته: در تنظیمات باتری اندروید، Termux را از «بهینه‌سازی باتری» مستثنی کن
> تا سیستم عامل آن را نکشد.

## 🎮 چطور بازی کنیم؟

1. **گروه بساز** — یک گروه تلگرامی بساز و ربات را به آن اضافه کن
2. **میزبان** → `/newgame` — کد اتاق ساخته می‌شود (مثل `K7Q2A`)
3. **بازیکن‌ها** → `/join K7Q2A` — ملحق می‌شوند (تا ۸ نفر)
4. **همه** → `/newchar` — نام، نژاد، کلاس و سلاح خود را انتخاب می‌کنند
5. **میزبان** → `/scenario` — هوش مصنوعی یک سناریوی کامل با دشمن‌ها و NPC می‌سازد
6. **شروع ماجرا** → `/story درِ کهنه را باز می‌کنم` — AI روایت می‌کند!
7. **نبرد** → `/combat` — نوبت‌ها خودکار می‌چرخد، دشمن‌ها خودشان حمله می‌کنند

## 📚 دستورات

```
🎮 جلسه        /newgame  /join <کد>  /party  /reset
🧙 کاراکتر     /newchar  /sheet  /levelup  /xp
🐉 دانجن‌مستر  /scenario <توضیح>  /story <اقدام>  /where
⚔️ نبرد        /combat  /attack <دشمن>  /cast <طلسم> <هدف>  /skip  /combatend
🎲 تاس         /roll 2d6+3  /roll d20  /roll adv  /roll dis
```

## 🗂 ساختار پروژه

```
dnd-bot/
├── main.py            # نقطه ورود ربات
├── config.py          # تنظیمات از فایل .env
├── game/
│   ├── rules.py       # نژادها، کلاس‌ها، سلاح‌ها، دشمن‌ها (D&D 5e ساده‌شده)
│   ├── dice.py        # موتور تاس
│   ├── models.py      # کاراکتر و جلسه بازی
│   ├── combat.py      # نبرد، نوبت‌بندی، XP
│   ├── narrator.py    # دانجن‌مستر هوش مصنوعی (Gemini/Groq/OpenRouter + آفلاین)
│   └── store.py       # ذخیره‌سازی SQLite
├── bot/
│   ├── handlers.py    # دستورات
│   ├── conv.py        # گفت‌وگوی ساخت کاراکتر
│   └── keyboards.py   # دکمه‌های شیشه‌ای
└── termux/
    ├── setup.sh       # نصب یک‌دستوری روی گوشی
    ├── run.sh         # اجرا با ری‌استارت خودکار
    └── boot.sh        # راه‌اندازی خودکار با روشن شدن گوشی
```
